# Saffron & Thyme — Italian-Indian Fusion Landing Page

A premium, modern, and highly aesthetic landing page template designed for high-end restaurants. This template features a sophisticated dark theme, elegant typography, smooth reveal animations, and a functional reservation form.

## QUICK START:
1. **View the Site**: Open `index.html` in any web browser to see the live design.
2. **Edit Content**: Right-click `index.html` and open it in VS Code, Sublime Text, or even Notepad to edit the text, menu items, and pricing.
3. **Change Styles**: All styling is contained within the `<style>` tag inside `index.html`. You can modify colors, fonts, and spacing directly there.
4. **Deploy for Free**: To put your restaurant online, upload this entire folder to [Vercel.com](https://vercel.com) or [Netlify.com](https://netlify.com). It works instantly without any setup!

## Features:
- **Premium Aesthetics**: A "Michelin-star" look with gold accents, deep burgundy tones, and a subtle film grain effect.
- **Fully Responsive**: Meticulously crafted to look stunning on iPhones, tablets, and large desktop screens.
- **Interactive Menu**: Category tabs for Antipasti, Primi, and Dolci to showcase your culinary offerings.
- **Smart Animations**: Intersection Observer based "reveal" animations that trigger as the user scrolls.
- **Reservation System**: A built-in booking form with success states, ready for backend integration.
- **Custom Map UI**: A stylized, minimalist map layout that matches the brand identity.

## Technology Stack:
- **Core**: Semantic HTML5 & Vanilla JavaScript
- **Styling**: Modern Vanilla CSS (using CSS Variables for easy color changes)
- **Typography**: Google Fonts (Playfair Display for elegance, Inter for clarity, JetBrains Mono for a modern touch)
- **Icons**: Custom SVG icons for socials and features

## Customization Tips for Beginners:
- **Changing Colors**: Look for the `:root` section at the top of the CSS to change the primary colors (like `--gold` or `--burgundy`) in one place.
- **Updating Images**: Replace the placeholder image tags (e.g., `[ Hero food photography ]`) with your own image URLs or local files.
- **Adding Your Menu**: Copy and paste the `<div class="dish">` blocks to add more items to your menu sections.
